# Raw Data

Large raw datasets are not committed to this repository.

The final notebook uses the processed tract-level checkpoint in `data/processed/`.
Raw inputs are only needed if the full preprocessing workflow is rebuilt locally.

Expected raw sources include:

- NYC 2015 Street Tree Census
- NYC Census tract boundaries
- NYC PLUTO / MapPLUTO
- NYC building footprints
- NYC parks data
- CDC/ATSDR Social Vulnerability Index
- UrbanWatch land-cover raster
